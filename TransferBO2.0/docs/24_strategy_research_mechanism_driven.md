# Step3 策略研究方案 — 机制驱动版（2026-08-24）

**定位声明：** 当前主策略（多源池化 top-5 init 清单）是**效应研究阶段的幸存者**，不是策略研究的产物。
本方案把策略从"效应结论"升级为"**机制设计的组件系统**"：每个策略组件必须对应一个已验证的机制，
机制给出组件的**激活条件**（什么时候用、用多少、什么时候弃权）。

**前置机制（`docs/19` §4.2、`results/rank_preservation/`）：**
1. 排序保持假说：迁移的是条件排序，不是绝对产率；
2. 双通道机制：init 价值 = 顶部排序保持；后段价值 = 响应面可学性；
3. 分工机制：清单吃主效应、EI 吃交互。

---

## 1. 机制 → 策略组件映射（策略设计的依据）

| 策略组件 | 机制依据 | 组件形式 | 待研究问题 |
|---|---|---|---|
| **A 清单组件**（init） | 顶部排序保持最稳 | 池化 top-5 + 源数门槛 + coverage | 已固化（效应+机制两层证据）|
| **B 续跑组件**（EI） | 后段价值 = 交互结构可学性 | EI 必选/可选/不做的**事前判别** | **未研究**：如何事前判断新任务的可学性（用历史源的主效应结构/交互强度作代理）|
| **C 门控组件**（选源/弃权） | 排序保持度可测且与增益相关 | 事前预测源-目标排序保持度 → 选源/加权/弃权 | docs/20 方案（未执行）|
| **D 报告组件** | 数值不可迁移 | 相对指标 + coverage + 风险提示 | 已固化（纪律）|

## 2. 研究顺序（Phase 0 先行：离线信号检测，零新实验）

| 阶段 | 内容 | 成本 | 决策门 |
|---|---|---|---|
| **Phase 0** | 元特征 × 迁移增益/模式 的关联与判别（四库靶级数据） | 离线半天 | 有信号 → Phase 1–3；无信号 → 如实写"事前判别在现有元信息下不可行"，策略维持"清单 + 保守默认" |
| Phase 1 | 规则门回放：coverage 门 / 相似度门 / 源数分档（四库 LOSO） | 中 | 按 Phase 0 信号选门形式 |
| Phase 2 | 探针式主动门：3–5 探针 → 源-目标一致性 → 选源/弃权（P0 matched-init 模板评估） | 中 | — |
| Phase 3 | 任务建模门：元特征 → 可解释模型 → leave-one-library-out；**含模式判别器**（init vs 后段 → B 组件激活） | 中 | — |

**Phase 0 元特征（全部事前可计算，仅用历史源）：**
- 源间排序一致性：Spearman 均值/方差（= 排序保持度，已有）；
- 高值区重叠：源间 top-10% 条件 Jaccard；
- 主效应结构：历史面板 additive R²（分工机制的代理）；
- 交互强度：1 − additive R²；
- 条件支持度与源数（coverage、n_sources）；
- 源内变异性（产率方差）。

**Phase 0 预测目标：**
- 靶级迁移增益（topk − cold ΔAUC，靶级）；
- 靶级模式标签（init 型 = carried Δ 占比 > 1；后段型 = topk post 显著大）。

## 3. 预注册判定（Phase 0）

| 结果 | 判定 |
|---|---|
| 至少一个元特征对迁移增益有显著靶级关联（p<0.05 且方向与机制一致） | **信号存在** → Phase 1–3 启动；B 组件按"可学性代理"设计 |
| 元特征可区分 init/后段模式（AUC ≥ 0.7，leave-one-library-out） | **模式可事前判别** → B 组件（EI 必选/可选）落地 |
| 全部无信号 | 如实报告"事前判别在现有元信息下不可行"；策略维持保守默认（清单 + 全库 EI 可选）；门控研究按 docs/20 三态收口为负结果 |

## 5. 明确不做

- 不在 Phase 0 有信号前设计 B/C 组件的具体实现（防止过拟合元特征）；
- 不引入目标标签参与元特征（事前可计算是硬约束）；
- 不复活"历史进 GP"（排序假说已证伪）；
- 不把 Phase 0 的判别模型直接当策略（必须过 Phase 1–3 的预注册评估）。

## 6. Phase 0 结果（2026-08-24，已执行）

**判定：Partial signal**（`results/strategy_phase0/`）。

| 检验 | 结果 | 读法 |
|---|---|---|
| 机制代理 vs 增益（pooled，n=71） | rank_corr vs ΔAUC：**r = +0.339（p = 0.004）** | ✅ 排序保持度与迁移增益显著正相关——机制成为可操作的预测变量 |
| 其他元特征 vs 增益 | history_pairwise_rho +0.257、top10_jaccard +0.245、additive_r2 +0.208、其余 ≈0 | 弱方向性 |
| **跨库判别力（关键）** | leave-one-library-out 判别高增益靶：**AUC = 0.47**（< 0.5，无判别力） | ❌ 元特征**无法跨库判别**哪个靶迁移增益大 |
| additive_r2 库内行为 | hitea −0.464（负）vs suzuki +0.056（无） | 不一致——B 组件（EI 事前判别）暂不可行 |

**Phase 0 锁定读法（docs/24 §3 第三行）：**

1. **机制本身再次确认**：排序保持度是可操作的预测变量（p=0.004），"迁移的是排序"从机制变成策略输入；
2. **事前元特征门控不可泛化**（AUC 0.48）→ Phase 1/3（元特征规则门/建模门）**降级**；
3. **机制指出的正确路径 = Phase 2 探针门**：排序保持度是**可测的**（几个探针点直接测源-目标 Spearman），机制从未承诺"元特征能猜中排序保持度"——猜不中，就直接测；
4. **B 组件（EI 必选/可选的事前判别）暂不可行**（additive_r2 库内不一致）→ 维持保守默认（init 型库 EI 可选、Suzuki 类按库类别 EI 必选）；
5. **与 P3 湿实验天然衔接**：湿实验方案（docs/23）已有锚点设计——锚点 = 探针，前瞻验证即探针门的前瞻评估。Phase 2 先用四库回放模拟探针门，再用湿实验前瞻验证。

**调整后的研究顺序：** Phase 0（完成）→ **Phase 2 探针门**（优先级提升）→ Phase 1/3（仅作对照，不预期可泛化）→ P3 湿实验前瞻。

## 7. 策略研究进度（2026-08-24，四步全部完成）

| 步 | 内容 | 结果 | 状态 |
|---|---|---|---|
| 1 清单规则 | rank 聚合 vs 均值规则（四库回放） | init 层 rank_median +1.78 显著；**AUC@20 复核（重跑四库 LOSO）**：pooled +1.5 持平、Suzuki +34.8（AUC@5 +20.3 显著）、**HiTEA −30.0（不显著，CI 含 0）** → **默认保持 mean；rank_median 仅 Suzuki 类可选；稀疏面板禁用**（`results/rankmed_audit_compare/`；2026-08-24 修复 HiTEA 条件特征退化后复核） | ✅ 结论修正（以主指标 AUC@20 为准） |
| 2 续跑事前规则 | additive R² 分档预测 C1 | **不可行**（R² 是库级量、靶级无变异；pooled p=0.35 无信号）→ 续跑决策 = 分库规则（C1 库级差异）+ 探针事中测量 | ✅ 负结果，路径收敛 |
| 3 探针门 | 5 点探针（= round-1 清单）测源一致性 → 选源/弃权（离线回放） | **init 层信号**：探针有效性 +0.319（p≈1e-35，四库全正）、G2 选源池化 init_best 三库正；**AUC@20 未验证**（单步 EI 协议内 G2 无操作空间——历史只用于 init 一次、EI 是 target-only）→ 定位为**批量协议（湿实验，每轮 5 个）下的待验证组件** | ⚠️ 待批量回放验证 |
| 4 组合协议 | mean 清单 + 分库续跑 + 探针门 + coverage 报告 | 组件证据齐备，组合为完整策略（见 docs/14 升级） | ✅ 收口 |
| 5 续跑 warm 实验（Suzuki 类四臂） | "全程把 topk 条件加入 BO"：A=topk+EI 无 warm；B=+top-5 历史行 warm；C=+全部历史 warm（≤120）；D=topk+random | **AUC@20：B vs A −59.1 [−139.0, −3.6] 显著负（Suzuki −102）、C vs A −28.5 [−66.2, +4.3] 负趋势**；C vs B +53（warm 广度 > 精度，但两者都不如无 warm 的 A）→ **历史数据不应以 warm 点进入 target GP；清单（init）是历史价值的正确载体**（`results/continuation_arms_compare/`；2026-08-24） | ✅ 负结果，路径收敛 |

**策略四组件最终形态（机制驱动，全部有证据）：**

| 组件 | 最终规则 | 证据 |
|---|---|---|
| A 清单 | **跨源产率均值 top-5（默认 mean）**；rank_median 仅 Suzuki 类（完整网格、排序保持低）可选，稀疏面板（HiTEA 类）禁用 | init 层 +1.78 显著 → **AUC@20 复核（2026-08-24）：pooled +1.5 持平、HiTEA −30.0 不显著**，故默认 mean（不改全面升级） |
| B 续跑 | 分库（init 型 EI 可选、Suzuki 类 EI 必选——C1 库级差异）+ 探针后事中确认 | 第 2 步负结果 + C1（Suzuki +75.5）|
| C 门控 | **round-1 后选源池化（G2）**：探针 = round-1 清单观测，免费；一致性低的源剔除后再池化 | 第 3 步：三库正增益 |
| D 报告 | coverage + 相对指标 + 源数门槛 | 固化 |

**探针门的关键性质**：探针就是 round-1 的 5 个条件本身——门控**零额外实验成本**（湿实验第 1 轮做完即可免费获得）。
