## 1. 定位声明（为什么现在研究门控）

1. **2.0 此前没有真正研究过门控。** `safe_gate` 只是 Step1 的附带策略臂（Spearman 门 + sim_weighted 续跑），其 null 结果（胺化 +11.5）不能外推为"门控不可行"——门控与已被证伪的"加权进 GP"绑定，且对照基准错误（见 §4）。
2. **1.0 的 TransferGate No-Go 不适用于 2.0。** 1.0 在 8 靶、pair 协议、Δfrac 终点下判定；其自身即声明"任务足够后再重做 Gate，避免小样本门控幻觉"。2.0 现有 4 库（含 33 任务 borylation）、LOSO 协议、matched-init 技术——条件完全不同。
3. **未认真评估的资产存在。** `topk_safe_gate`（相似度阈值门）代码已注册但从未正式评估；P1/P2 的 source coverage 是条件级门控的雏形；Suzuki 上附带版 safe_gate vs cold = +80.7（CI 排除 0）提示门控在 Suzuki 类可能有信号。
4. **门控的边际空间来自"稳定性"而非"均值"。** 胺化 topk 已 13/15 靶赢，二元门（用/不用）无空间；价值在连续筛选（选源/加权/条件过滤/弃权）与风险降低。

## 2. 问题定义

> 给定历史数据 H（多源）与新底物 t（仅元信息，无标签或仅少量探针），门控决策 G 输出：源子集选择 S'⊆S、条件级过滤（coverage）、加权方案 w、或弃权 → 使最终协议相对"无门控全池化 topk"在**均值不降**的前提下**显著降低负迁移风险**。

**门的连续化谱系（用户定义，本方案采用）：**

| 形式 | 决策粒度 | 示例 |
|---|---|---|
| 二元门 | 全局（用/不用历史） | 弃权 → cold |
| 源级门 | 源子集 | 选"响应面一致"的源池化 |
| 条件级门 | 推荐条件 | coverage ≥ N 才推荐（P1/P2 雏形） |
| 连续门 | 源/条件加权 | 相似度或一致性加权 |
| **任务建模/主动学习门** | 学习式筛选 | 元特征预测可迁移性；探针评估源-目标一致性 |

## 3. 三个方法族（并行设计，择信号执行）

### A. 静态规则门（最低成本）
- **A1 coverage 门**：推荐条件要求跨源支持数 ≥ N（N ∈ {3,5,all}），池化规则不变；
- **A2 topk_safe_gate 回放**：底物相似度阈值（Morgan Tanimoto）决定 topk_warm vs cold，四库 LOSO 正式评估（这是它第一次被正式评估）；
- **A3 源数门槛的连续化**：按可用源数分档（<3 弃权、3–5 全池化、≥5 全池化 + coverage 过滤）。

### B. 探针式主动门（P0 技术复用）
- 新底物先做 **n_probe ∈ {3,5}** 个探针（随机 / 锚点 / 历史 topk 中选）；
- 用探针响应计算源-目标一致性（Spearman ρ、高值区重叠、排序一致），
  输出：选源子集 / 加权 / 弃权（弃权 = 退回 cold_start）；
- **探针设计本身用 matched-init 方法评估**（P0 遗产）：同一探针集下比较"门控后策略 vs 无门控策略 vs cold"，隔离探针信息价值；
- 预算语义：探针计入 B=20（n_init 段）；与冻结协议不冲突。

### C. 任务建模 / 元学习门（用户提出的核心方向）
- **元特征**（全部**事前可计算**，不使用目标标签）：
  - 源间响应面一致性（配对 Spearman、top-10% 高值区重叠、排序 Kendall）；
  - 条件级支持度分布（coverage 均值/方差）；
  - 源内响应面地貌（产率方差、高值区集中度 Gini、失败率）；
  - 底物相似度（Morgan Tanimoto 到各源的距离）；
  - 历史规模（源数、每源条件数）。
- **预测目标**：源-目标迁移增益符号/量级；以及**新任务属于 init 还是后段模式**（服务"要不要 EI 续跑"决策）；
- **验证协议**：leave-one-library-out（在 3 库训练 → 第 4 库验证），杜绝库内泄漏；模型限可解释族（logistic / GBDT / 线性），不做黑箱；
- **与既有结论的接口**：若 C 能事前预测模式，则"门控"升级为"模式感知策略选择"（init 模式 → 清单为主；后段模式 → 清单 + EI 必选）——这是门控的最高形态。

## 4. 评估协议（冻结，跑前写死）

**对照基准（关键修正）：** 门控的对手是**全池化 topk_warm**，不是 cold。门控若只求均值必然 null；它卖的是风险降低。

| 项 | 锁定值 |
|---|---|
| 协议 | LOSO；n_init=5（探针含在内）、B=20、EI、k=5、OHE——与冻结协议一致 |
| **主指标 1** | ΔAUC vs 全池化 topk（靶级 bootstrap 95% CI，B=5000） |
| **主指标 2** | **NTR**（低于全池化 topk 的靶比例）与 **worst-decile 提升**（最差 25% 靶的 AUC 变化） |
| 次指标 | init_best、AUC@5/10、final_best、轮次（T_50/命中高产区） |
| 推断单位 | 先 seed 平均 → target 汇总 → bootstrap CI（同冻结口径） |
| 库 | 胺化（15）、EDBO Suzuki（12）、borylation（33）、HiTEA Suzuki（11）；每库独立报告，禁止跨库合并 LOSO |
| seeds | 0–4（与冻结一致；SI 可加） |

**预注册判定（三态）：**

| 结果 | 判定 |
|---|---|
| 门控 vs 全池化 topk：ΔAUC ≥ 0 且 CI 下沿 ≥ −ε，且 **NTR 显著降低**（CI 排除 0） | **门控成立**（稳定性卖点兑现） |
| ΔAUC 不降但 NTR 未显著降 | 门控无增量 → 如实报告"均值-风险无置换" |
| ΔAUC 下降且 NTR 未降 | 该门无效 → 停止该族，不调参硬凑 |

**停止规则：** Phase 0 元特征与迁移增益无相关（|ρ| < 0.2 且无结构）→ 全族停止，写"门控在现有元信息下不可行"（负结果也是结论）。

## 5. 执行阶段（不急着做，但顺序固定）

| 阶段 | 内容 | 成本 | 前置 |
|---|---|---|---|
| **P0** | 离线元特征 × 迁移增益相关性分析（四库现有 LOSO 结果 + 事前特征，零新实验） | 0（本地半天） | — |
| **P1** | A 族回放：A1 coverage 门、A2 topk_safe_gate 四库 LOSO（新跑，~1k jobs） | 低（超算） | P0 有信号 |
| **P2** | B 族探针实验：探针点数/选择策略网格（每库 2–4 任务 × 小 seed 集先行） | 中 | P0 支持探针一致性可测 |
| **P3** | C 族任务建模：元特征表 + 可解释模型 + leave-one-library-out | 中（离线为主） | P0 特征有效 |
| **P4** | 模式预测接入：预测 init/后段模式 → 策略选择（清单 vs 清单+EI） | 中 | C 族验证通过 |

## 6. 明确不做

- 不做复杂 MTGP / 深度迁移模型（门控是筛选决策，不是建模炫技）；
- 不在外部库调 k / 换池化规则 / 换表示（冻结协议）；
- 不用门控结果回写 FROZEN_CLAIMS 与 Step1/2 主表；
- 不把 1.0 Gate No-Go 当作 2.0 结论引用（§1）；
- 不用目标标签参与门控特征（事前可计算是硬约束）；
- 不做"门控 + 加权进 GP"的组合（加权进 GP 已证伪，不复活）。
