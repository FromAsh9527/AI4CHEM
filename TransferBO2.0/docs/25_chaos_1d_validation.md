# CHAOS 一维独立验证（1-D validation, Prieto Kullmer et al., Science 2022）

**日期：** 2026-08-24  
**数据：** CHAOS additive screen 四板（`TransferBO/data/processed/additives_four_plates.csv`），4 个固定反应（plate_1..4）× 720 个共享添加剂完全交叉（2880 格）；响应 = UV210 产物面积（越大越好）。  
**角色：** 一维边界验证（docs/18 §2 曾以"一维"否决其作为正式验证库；2026-08-24 用户指示将其作为**一维独立验证**补充执行）。  
**结果：** `results/chaos_validation/{summary.md, per_target.csv}`；库：`data/db/transferbo2_chaos.db`；ingest：`scripts/ingest_chaos.py`；分析：`scripts/analyze_chaos_validation.py`。

## 1. 设计

| 项 | 取值 | 说明 |
|---|---|---|
| 任务（底物维度） | plate_1..4（4 个反应） | 一板一反应；"新底物"在这里 = 新反应 |
| 条件空间 | 720 添加剂（SMILES） | **一维**（只有添加剂变化；无配体/碱/溶剂网格） |
| 响应 | 板内 z(log1p(UV area)) | 四板 UV 尺度差 ~10 倍（中位 34k vs 3.8k），原始池化会被高尺度板主导——板内标准化**去掉水平、保留排序**，正是"数值不可迁移"假说的操作化 |
| 协议 | 与四库一字不差：LOSO、n_init=5、B=20、EI、seeds 0–4、mean 规则、OHE | 冻结协议 |

## 2. 结果

### 2.1 排序保持（假说的极端检验）

跨 4 反应（6 对）添加剂排序 Spearman **mean = 0.694**（各对 0.838/0.622/0.748/0.604/0.721/0.628）。

**五库对照**：CHAOS 0.694 > 胺化 0.577 > borylation 0.361 > EDBO Suzuki 0.264 > HiTEA 0.088。

→ 一维空间下排序保持**最高**：没有多维交互稀释，"添加剂本征好坏"跨反应保持最强。

### 2.2 策略对比（AUC@20，配对 bootstrap CI，n=4 仅方向性）

| 对比 | Δ AUC@20 | 95% CI | 4/4 靶为正 |
|---|---|---|---|
| **topk vs cold** | **+8.08** | [+4.29, +12.73] | 是 |
| **topk vs random** | **+10.66** | [+5.83, +16.37] | 是 |
| topk vs topk_random（EI 后段价值） | +0.00 | [0, 0] | — |
| cold vs random | +2.58 | [+1.53, +3.64] | 是 |
| nearest vs cold | +7.45 | [+3.83, +11.28] | 是 |

**AUC@20 绝对值**：topk_warm 24.0 ≈ nearest 23.4 > cold 15.9 > random 13.3。

### 2.3 关键机制观察：清单一次吃光信号（极端 init 模式）

- **topk vs topk_random 严格为 0（全部 4 靶 × 5 seeds）**：不是 bug。板内 z 标准化后，池化 top-5 的 init_best 已达 ~0.9–1.0σ（排序保持 0.694 ⇒ 清单几乎必含该板最佳添加剂），后段无论 EI 还是随机都无法再提升 best-so-far——**BSF 曲线自 init 起恒为 init_best**；
- **EI 尾段退化为顺序扫描**（indices 0,1,2,…）：720 维 one-hot + 5 个 init 点，协议 GP 无法对剩余条件排序（`docs/19` 已记录的"协议 OHE 零样本排序 ≈ 0"效应）——**排序由清单携带，GP 学不动**；
- 这与胺化/borylation 的 init 模式同族，但更极端：**1-D 空间下清单=全部信号**。

## 3. 读法与边界

1. **清单机制不需要多维条件结构**：在最简单的 1-D 设定下，跨反应池化 top-5 清单依然正增益（4/4 靶），排序保持假说在五库中表现最强；
2. **n=4 任务：只能报方向**（全部 CI 排除 0 是因为靶内 seed 平均后差异稳定，但靶数少、且 AUC 单位是 z 产率，与四库产率单位不可比——不报相对增益%）；
3. **后段无操作空间是特征（1-D 高保持）的结果，不是协议缺陷**：湿实验（docs/23）SNAr 是 3-D 条件空间，仍有交互结构可学；
4. **不进入主证据**：作为边界/鲁棒性补充（SI 或 Discussion），主证据仍为四库 + P3 湿实验。

## 4. 与 docs/18 §2"一维否决"的关系

docs/18 否决 CHAOS 作正式验证库的标准是「条件维度 > 1 + 任务 ≥8 + 共享条件 ≥100」——该否决**维持不变**（4 任务、1-D 不足以支持强声明）。本次执行的是用户指示的**一维独立验证**：回答"清单机制是否依赖多维条件结构"，答案是**不依赖**，且一维下排序保持最强。定位：边界验证，不进验证主链。
