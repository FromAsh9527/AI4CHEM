## 3. 给机械臂用的储备液（仅 para / 2017）

目标：每管液体加样 **≥20 µL**，避免 2 mg Pd 直接自动称量。

建议母液（HFIP，当天配、避光）：

| 母液 | 浓度 | 配 2.0 mL | 每管取样 | 每管物质的量 |
|------|------|-----------|----------|----------------|
| Pd(OAc)2 / HFIP | 0.050 M | 22.5 mg / 2.0 mL | **200 µL** | 0.010 mmol |
| L1 / HFIP | 0.150 M | 62.4 mg / 2.0 mL | **200 µL** | 0.030 mmol |
| 1a / HFIP | 0.500 M | 250 mg / 2.0 mL | **200 µL** | 0.100 mmol |
| 丙烯酸乙酯 / HFIP | 1.50 M | 300 mg（326 µL）/ 2.0 mL | **200 µL** | 0.300 mmol |
| 茴香醚 / HFIP（2017） | 0.500 M | 108 mg / 2.0 mL | **200 µL** | 0.100 mmol |

然后 **补 HFIP 至 1.00 mL**（约再加 200 µL，视是否另加 Ag）。

**AgOAc 不要配真溶液。** 每管仍手工称 **50.1 mg** 预置瓶底，或（仅当有粉末加样头时）固体加样。HFIP 中是悬浊，枪头吸浆会堵、浓度漂移。

加样顺序建议：瓶中先有 AgOAc（及可选固体 Pd）→ 机械臂加 Pd 液、配体液、底物液、烯烃液 → 补 HFIP → 旋盖 → 加热块。

## 4. 自动化设备能不能做？

仓库里只有「机械臂加液 → 密封小瓶 → 稀释进样」，**没有品牌/温度上限/是否有固体模块**。下面按这类平台的典型能力评估。

### 4.1 结论（可直接上 PPT）

| 反应 | 机械臂能否做 | 原因 |
|------|----------------|------|
| **2024 para（80 °C，HFIP，空气）** | **能，建议杂交：人称为 Ag/Pd 固体，机器加液体** | 体积 1 mL、空气、80 °C、10 mL 瓶，和标准小瓶加热块匹配 |
| **2017（~90 °C，HFIP）** | **能，同上** | 与 para 同一套方法 |
| **2024 meta（140 °C，0.25 mL，Cu 盐）** | **第一轮不要上机械臂** | 超多数加热块安全上限；溶剂在沸点以上；Cu/Ag 多种固体；后处理要 Na2S 淬灭 |

### 4.2 单元操作对照

| 步骤 | para / 2017 | 典型机械臂小瓶台 | 风险 |
|------|-------------|------------------|------|
| 液体（底物、烯烃、HFIP、配体溶液） | 20–200 µL | 通常可以 | HFIP 腐蚀部分针座胶、挥发快，用 PTFE 针 / 耐氟塑料头，加样后尽快盖盖 |
| Pd(OAc)2 2.2 mg 固体 | 太少 | **多数没有准到 2 mg 的固体头** | 必须母液或手称 |
| AgOAc 50 mg | 可称 | 有粉末模块才自动 | **无固体头则手称预装** |
| 80–90 °C、20–24 h、拧盖 | 需要 | 多数加热振荡块可以 | 确认盖子 PTFE 垫、扭矩，HFIP 回流别漏 |
| 空气气氛 | 要 | 不需要手套箱 | 好做 |
| 反应后稀释进 GC | EA 定容 | **很适合机械臂** | 先 Celite 滤 Ag，或离心取上清再吸 |
| 140 °C / 20 h | meta | 很多模块标称 ≤120 °C | 压力 + 爆瓶；放到独立加热块/油浴 |
| Na2S 水溶液淬灭 | meta | 湿化学、臭、腐蚀 | 人工后处理 |

### 4.3 建议 SOP（和开题「平台」一致、又不怕翻车）

1. **第一批 8 管 para+2017**：人手称 AgOAc（±0.5 mg）进预编码瓶子 → 机械臂加四种 HFIP 母液 → 拧盖 → 80–90 °C 加热块。  
2. 反应后：机械臂加 EA + 内标，取上清进 GC；NMR 产率仍手加 CH2Br2。  
3. **meta**：等 para 通了、L2/L3 到了，**手工 10 mL 耐压瓶 + 油浴 140 °C**，不要为了「全自动」把 140 °C 塞进未验证的模块。  
4. 若老师问「能不能全自动」：可以说 **位点数据生产的主路径（para、80 °C、HFIP）可以上臂**；meta 是对照实验，通量低，手工更安全。

### 4.4 上机前向设备管理员确认的 6 句话

1. 加热块最高温度、是否允许 **HFIP 过夜**？  
2. 枪头/针是否 **耐 HFIP**？  
3. 有没有 **固体加样**，精度多少 mg？  
4. 瓶子规格是否 **10 mL 螺纹 + PTFE 垫**？  
5. 能否 **振荡**（Ag 盐悬浊需要）？  
6. 反应后液体是否允许直接吸到 GC 小瓶（Ag 粉过滤怎么做）？

管理员若答「只有加液 + ≤100 °C」，则 **para 仍可做**（文献 80 °C），2017 可先 80 °C 试一管再升到 90 °C。
