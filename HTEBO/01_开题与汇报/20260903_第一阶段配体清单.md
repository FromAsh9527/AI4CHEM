# 第一阶段配体清单（2017 / 2024 Yu 组复现）

结论先说：**真正要准备的配体只有四个编号、三种吡啶酮 + 一种商品化吡啶。**  
不要把 L1 和 L69 当成同一个；不要用 5-CF3-2-吡啶酮冒充 2017 最优配体去做「复现」。

| 编号 | 结构（不要写错取代基） | 对应反应 | 怎么拿 | 现在就做？ |
|------|------------------------|----------|--------|------------|
| **L69** | **3,5-双(三氟甲基)-2-吡啶酮** | **2017 Nature** 烯基化最优配体 | 先查货；买不到再按已有四步合成 | **是（档 A）** |
| **L1** | **3-硝基-5-三氟甲基-2-吡啶酮** | **2024 para** | **买**，不要合成 | **是（档 A）** |
| **L2**（文献也叫 **L11**） | 桥碳 `CMe2` 的 **六元螯合吡啶–吡啶酮** | **2024 meta** 双齿配体 | **必须合成** | 与档 A 并行，但 meta 可后做 |
| **L3** | 单齿吡啶（商品） | **2024 meta** 共配体 | **买**，不要合成 | meta 开做前买齐即可 |

## 1. 为什么是这几个（对过 SI，不再「待查」）

### 2017 *Nature* 551, 489（Wang / Yu）

- SI §3.2 标题就是 **Synthesis of 2-Hydroxypyridine Ligand L69**。
- SI 通用操作：芳烃 0.10 mmol、丙烯酸乙酯 0.20 mmol、`Pd(OAc)2` 10 mol%、**L69 6.9 mg（30 mol%）**、`AgOAc` 50.1 mg、HFIP 或 CHCl3 **0.50 mL**、**100 °C / 24 h**。
- 茴香醚（SI 底物 **1f**，HFIP）：总产率 67%，**o/m/p = 1.8/1.0/3.7**，另有约 20% 双烯基化。
- SI 还扫过其它羟基吡啶（Scheme S2–S5）和 **L31** 当量；**复现只做 L69**，不必把筛选表全合成一遍。

**L69** = 3,5-bis(trifluoromethyl)pyridin-2(1H)-one  
`C7H3F6NO`，MW **231.09**；常见 CAS **38609-76-6**（2-羟基-3,5-双三氟甲基吡啶）。  
¹H NMR (CDCl3)：δ 8.04 (s, 1H), 8.03 (s, 1H)；¹⁹F：δ −62.70, −66.59。

### 2024 *ACS Catal.* 14, 12806（Meng / Yu）

- **para**：正文锁定 **L1 = 3-nitro-5-trifluoromethyl-2-pyridone**，30 mol%，HFIP，80 °C，空气，20 h；标杆 74%，**p:o:m ≈ 17:1:1**。
- **meta**：六元螯合 **pyridine–pyridone L2**（10 mol%）+ 单齿 **pyridine 共配体 L3**（1.0 equiv）；`Cu(OPiv)2`，叔戊醇，140 °C；标杆 65%，**m/p ≈ 8/1**。
- SI 注明：Table S3 配体「商品化或按先前报道制备」。L2 来自 2023 *JACS* 双配体工作中的 **L11**（Meng et al., DOI: 10.1021/jacs.3c01631）。

**L1** 与 **L69 不是同一个分子**：L1 是 3-NO2 / 5-CF3；L69 是 3-CF3 / 5-CF3。para 复现必须用 L1。

### L3 — 2024 meta 共配体（买，三种都便宜）

2024 正文写的是 **pyridine co-ligand L3**；2023 同源双配体体系用过 **吡啶** 和 **3,5-lutidine**。现有投料表暂按 **2,6-lutidine** 占位。三者都商品化、几毫升就够，**不要合成、也不要只订一种**。

| 候选 | CAS | 单管（1.0 equiv / 0.10 mmol） | 建议买 |
|------|-----|------------------------------|--------|
| 吡啶 | 110-86-1 | 7.9 mg / 8.1 µL | 25 mL 试剂瓶 |
| **3,5-lutidine**（2023 机制实验常用） | 591-22-0 | 10.7 mg / ~12 µL | **5 mL，优先** |
| 2,6-lutidine（投料表占位） | 108-48-5 | 10.7 mg / 11.6 µL | 5 mL |

开 meta 前用 SI 结构图锁定哪一个是 L3；在此之前三种都放抽屉里。

## 3. 不要准备 / 不要拿来冒充复现

| 化合物 | 为什么出现 | 怎么处理 |
|--------|------------|----------|
| 5-CF3-2-吡啶酮（CAS **33252-63-0**） | 2017 筛选表里的简单类似物，很好买 | **可选 1 g 备份**，不能替代 L69 报「2017 复现成功」 |
| 未取代 2-吡啶酮 | 同样是筛选对照 | 不做复现主配体 |
| 2024 SI 全套吡啶酮扫描 | para 优化过程 | **只买 L1** |
| 2023 L12–L18 电子/立体变体 | meta 配体优化 | 第一阶段 **只做 L11/L2** |
| 2017 远程导向 / 腈模板配体 | 另一条 Yu 组线 | 与无导向主线无关 |

## 4. 准备顺序（一个人、配体先于烯基化）

```
本周     下单 L1（P0）+ 查 L69 是否有货
         同时订 L2 合成原料（2-甲基吡啶、2,6-二氟吡啶、n-BuLi、KOtBu、MeI）
         若 L69 无货：订 S4、NIS、BnBr、Chen 试剂、Pd(OH)2/C
         L3：吡啶 + 3,5-lutidine + 2,6-lutidine 各一小瓶

到货后   档 A 可以立刻开：2017（L69）+ 2024 para（L1）
         L2 三步合成与档 A 并行（−78 °C / MeI 那天不要排氢化）

L2 有 NMR 后再开 2024 meta（L2+L3）
```

| 优先级 | 没有它就不能做什么 |
|--------|-------------------|
| **P0** | 没 **L1** → 2024 para 开不了 |
| **P0** | 没 **L69** → 2017 不能叫复现（可先做 para，但 2017 空白对照要等） |
| **P1** | 没 **L2** → meta / 位点反转对照做不了；para 仍可做 |
| **P2** | **L3** 货期短，跟着 meta 一起买 |

## 6. 和后面实验的接口

- 档 A 只需要 **L1 + L69** 在手，外加 TIPS-苯酚 **1a**（底物，不是配体）。
- 档 B 的位点反转对照（C1 = L2+L3，C0 = meta 条件改用 L1）才需要 L2。
- 配体合成不上机械臂；自动化留给 para / 2017 小瓶。
